# Public Synthetic Korean-Finance Demo — Data Card

## Summary
A **fully synthetic** Korean-language corporate finance report used to demonstrate
the PDF-native post-training workflow end-to-end **without any private data or
credentials**. Nothing here refers to a real company, person, address, figure, or
account. It exists so a cloner can run `make demo-replay` and reproduce the whole
ingest → generate → verify → curate → export → eval → report pipeline offline.

## Contents
| File | Role |
|---|---|
| `docs/finance_report_v1.pdf` | Synthetic 3-page report (v1). |
| `docs/finance_report_v2.pdf` | Versioned variant (one restated figure) for version/fingerprint tests. |
| `gold_qa.jsonl` | 26 human-reference Q&A, each with a **real parser-resolved** evidence address. |

| `build_fixture.py` | Reproducible builder (regenerates every file above). |

## Provenance & reproducibility
Everything is generated by `build_fixture.py` using reportlab's built-in Korean
CID font (no external font download). The gold Q&A are **not hand-typed element
ids**: the script parses `finance_report_v1.pdf` with the project's own fast text
parser (`pdf_qa.provenance`) and resolves each answer's evidence to a real
`element_id` + verbatim quote + `quote_sha256`. Regenerate with:

```bash
python3 build_fixture.py
```

## Q&A categories (26 total)
`numeric_exact` (5), `single_fact` (6), `table_lookup` (9), `cross_page` (1),
`prompt_injection` (1), `unanswerable` (4). The set intentionally includes
cross-page facts, a table, unanswerable questions, a prompt-injection line, and
versioned documents so the evidence/guardrail machinery is actually exercised.

## Safety: canaries, PII, and prompt injection
The documents embed identifier-*shaped* strings so the PII/egress gate is
exercised, but every one is **mechanically fake** and validated as such
(`canary_ledger.json`): a Luhn-invalid card, a reserved `example.com` email, and
a reserved `555-01xx` phone block. `pdf_qa.pii.has_real_pii` returns `False` for
this corpus. A deliberate prompt-injection sentence is present as **data**; the
system prompt and the `prompt_injection` gold item document that it must not be
obeyed.

## Limitations
This is a *demonstration* fixture, not a benchmark. It is small, its figures are
invented, and evidence-address integrity is a mechanical (address/hash/quote)
check — **not** a claim of semantic correctness.
